GitHub & Firebase 無料公開手順

インターネット上に完全無料で公開・共有する方法

このアプリ（`index.html` 単一ファイル）をGitHubとFirebase Hostingにアップロードし、独自URLで世界に公開する手順です。

1

Firebase プロジェクトの作成と Google ログイン有効化

1. Firebase Console にアクセスし、「プロジェクトを追加」をクリックします。

2. プロジェクト名（例: agri-calc）を入力して作成します。

3. Authentication 設定: 画面左メニュー「構築」→「Authentication」→「始める」→「Google」を選択して有効化します。

4. Firestore 設定: 「Firestore Database」→「データベースの作成」→テストモードで開始します。

5. Web アプリ追加: プロジェクト概要画面で「Webアイコン ()」をクリックし、アプリを登録後、表示された firebaseConfig の値をコピーします。

2

GitHub リポジトリの作成

1. GitHub New Repository にアクセスします。

2. リポジトリ名 fertilizer-calc-app を入力し、「Create repository」をクリックします。

3. ダウンロードした index.html をリポジトリのルートに配置して Commit/Push します。

3

Firebase CLI でデプロイ (Hosting)

ターミナル（またはコマンドプロンプト）で以下のコマンドを実行します：

# Firebase CLI のインストール
npm install -g firebase-tools

# Firebase にログイン
firebase login

# プロジェクトの初期化
firebase init hosting

# （質問にはPublic directory: ".", Single page app: "Yes" と回答）

# ホスティングへデプロイ！
firebase deploy --only hosting

デプロイ完了後、発行された https://YOUR-PROJECT.web.app でアプリが全世界へ一般公開されます！
