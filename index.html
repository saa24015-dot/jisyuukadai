Firebase ＆ GitHub デプロイ・公開ガイド

この単一HTMLファイルWebアプリをご自身のFirebaseプロジェクトやGitHub Pagesへデプロイして全世界へ公開する手順です。

Step 1

Firebase Authentication（Google Auth）設定

1. Firebase Console でプロジェクト作成。
2. 「Authentication」>「Get Started」>「Google」を有効化。
3. 「承認済みドメイン」に開発ドメインやlocalhostを追加。

Step 2

Firestore セキュリティルールの設定

ログインユーザー本人のみが自身のデータを読み書きできるルールを適用します：

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /artifacts/{appId}/users/{userId}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}
Step 3

Firebase CLIで Hosting 初期化 ＆ デプロイ

ターミナル等で以下のコマンドを実行し、Firebase Hostingへ1発デプロイします。

# Firebase CLIのインストール
npm install -g firebase-tools

# Firebaseログイン
firebase login

# プロジェクト初期化
firebase init hosting

# 1発デプロイ！
firebase deploy --only hosting
Step 4

GitHub リポジトリヘのプッシュ

コードをGitHubに保存・バージョン管理する場合の標準コマンドです。

git init
