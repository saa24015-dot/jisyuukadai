📖 Firebase ＆ GitHub 無料公開ガイド

このアプリを完全無料でWeb公開・運営するための手順書です。

1. Firebase プロジェクトの設定

  1. Firebase Console にアクセスして新規プロジェクトを作成。
  2. Authentication メニューから「Google」認証プロバイダを有効化。
  3. Cloud Firestore を作成（テストモードで開始）。
  4. プロジェクト設定からWebアプリを追加し、`firebaseConfig` をコピー。

2. コマンドラインでデプロイ

# 1. Firebase CLI インストール

npm install -g firebase-tools

# 2. ログイン & 初期化

firebase login

firebase init hosting

# 3. 本番デプロイ

firebase deploy
